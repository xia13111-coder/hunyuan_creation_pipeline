# Hunyuan Creation Pipeline

Production-oriented asset pipeline for Tencent Hunyuan 3D assets and existing GLB models. The project can generate GLB assets from images or prompts, optionally refine Hunyuan meshes, convert GLB to USD, add physics properties, and collect final USD assets for downstream simulation use.

## Features

- Tencent Hunyuan 3D batch generation from image folders, image URLs, or text prompts.
- Mesh refinement path for Hunyuan-generated GLB assets.
- Generic back-half pipeline for hand-made or third-party GLB models.
- Blender-based axis alignment, resizing, centering, and GLB to USD conversion.
- Isaac Sim-based physics material, collision, rigid body, and mass authoring.
- Final USD asset collection with flattened material and texture references.
- Direct Python runner and optional HTTP API/Docker deployment.

## Pipeline Modes

### 1. Hunyuan Generate And Process

Use this for assets generated by Tencent Hunyuan 3D.

```text
image folder / image URL / prompt
-> Hunyuan GLB generation
-> refine mesh
-> axis align
-> resize and center
-> GLB to USD
-> add physics
-> collect final USD
```

### 2. Existing Hunyuan GLB

Use this when a Hunyuan GLB already exists locally and should still go through refine mesh plus the normal post-process chain.

```text
existing Hunyuan GLB
-> refine mesh
-> axis align
-> resize and center
-> GLB to USD
-> add physics
-> collect final USD
```

### 3. Manual Or Third-Party GLB

Use this for hand-modeled or third-party GLB assets. This path skips Hunyuan generation and mesh refinement.

```text
manual GLB
-> GLB to USD
-> add physics
-> collect final USD
```

Manual GLB mode preserves the authored geometry orientation. It writes USD `upAxis = "Z"` metadata but does not rotate or bake the GLB geometry.

## Requirements

- Linux with NVIDIA GPU for Isaac Sim workflows.
- Conda environment from `environment.yml`.
- Blender, usually `/opt/blender/blender`.
- Isaac Sim, for example `/home/user/isaacsim500/python.sh`.
- Tencent Cloud credentials only for Hunyuan generation or Hunyuan refine mesh.

The runner auto-detects common Blender and Isaac Sim paths. You can override paths with:

```bash
export BLENDER_BIN=/opt/blender/blender
export ISAACSIM_ROOT=/home/user/isaacsim500
export ISAAC_PYTHON=/home/user/isaacsim500/python.sh
```

## Setup

Create or update the conda environment:

```bash
conda env create -f environment.yml
conda activate hunyuan
```

For an existing environment:

```bash
conda env update -f environment.yml --prune
```

Set Tencent Cloud credentials when running Hunyuan generation or refine mesh:

```bash
export TENCENTCLOUD_SECRET_ID="your-real-secret-id"
export TENCENTCLOUD_SECRET_KEY="your-real-secret-key"
```

Do not commit real credentials.

## Quick Start

### Hunyuan Full Pipeline

Put input images in `data/`, then run:

```bash
cd /path/to/hunyuan_creation_pipeline

/home/user/miniconda3/envs/hunyuan/bin/python ./run_asset_pipeline.py \
  --input-dir ./data \
  --output-dir ./downloads \
  --intermediate-output-dir ./output_intermediate \
  --final-output-dir ./output_final \
  --result-json ./pipeline_result.json \
  --face-count 150000 \
  --len-x 0.4 \
  --len-y 0.3 \
  --len-z 0.3 \
  --orientation "X=L,Y=M,Z=S" \
  --material plastic \
  --approx sdf
```

### Existing Hunyuan GLB

```bash
/home/user/miniconda3/envs/hunyuan/bin/python ./run_asset_pipeline.py \
  --existing-glb ./downloads/example_asset \
  --intermediate-output-dir ./output_intermediate \
  --final-output-dir ./output_final \
  --result-json ./pipeline_result.json \
  --len-x 0.4 \
  --len-y 0.3 \
  --len-z 0.3 \
  --material plastic \
  --approx sdf
```

### Manual GLB

```bash
/home/user/miniconda3/envs/hunyuan/bin/python ./run_asset_pipeline.py \
  --manual-glb "/home/user/downloads/example.glb" \
  --intermediate-output-dir ./manual_output_intermediate \
  --final-output-dir ./manual_output_final \
  --result-json ./manual_pipeline_result.json \
```

For the local welding-machine sample:



## Important Conventions

### USD Up Axis

The USD stage is authored as Z-up by setting USD `upAxis = "Z"`.

Manual GLB mode does not rotate or bake source geometry. This is intentional: the pipeline preserves the modeler's authored orientation and only writes the USD stage metadata.

### Mass

`--set-mass` means total asset mass in kilograms.

- If the USD contains one rigid body, the full value is written to that body.
- If the USD contains multiple rigid bodies, the value is distributed by volume weight.
- If `--set-mass` is omitted, mass is estimated from volume and material density.

### Collision Approximation

Common `--approx` values:

- `sdf`
- `convexHull`
- `convexDecomposition`
- `triangleMesh`
- `meshSimplification`
- `boundingCube`
- `boundingSphere`

For dynamic rigid bodies, `sdf` is the safest default for complex meshes.

## Key CLI Options

| Option | Meaning |
| --- | --- |
| `--input-dir` | Image directory for Hunyuan generation. |
| `--prompt` | Text prompt for Hunyuan generation. |
| `--image-url` | Remote image URL for Hunyuan generation. |
| `--existing-glb` | Existing Hunyuan-style GLB path, still runs refine mesh. |
| `--manual-glb` | Existing manual or third-party GLB path, skips generation and refine mesh. |
| `--len-x`, `--len-y`, `--len-z` | Target size in meters for resize-capable paths. |
| `--orientation` | Axis mapping used by `align_glb_axis_only.py`. |
| `--material` | Material preset name from `materials.json`. |
| `--approx` | Collision approximation mode. |
| `--set-mass` | Total asset mass in kilograms. |
| `--skip-refine` | Skip refine mesh for existing GLB workflows. |
| `--usd-format` | USD output format for manual/general GLB mode. |

Run help for the full option list:

```bash
/home/user/miniconda3/envs/hunyuan/bin/python ./run_asset_pipeline.py --help
```

## Troubleshooting

### `ModuleNotFoundError: No module named 'yaml'`

Install PyYAML in the active environment:

```bash
/home/user/miniconda3/envs/hunyuan/bin/python -m pip install "PyYAML>=6.0"
```

### `latin-1 codec can't encode characters`

The Tencent credential environment variables probably contain placeholder text or non-ASCII characters. Re-export real credentials:

```bash
unset TENCENTCLOUD_SECRET_ID
unset TENCENTCLOUD_SECRET_KEY
export TENCENTCLOUD_SECRET_ID="your-real-secret-id"
export TENCENTCLOUD_SECRET_KEY="your-real-secret-key"
```

### `Executable not found: /isaac-sim/python.sh`

Set the local Isaac Sim path:

```bash
export ISAACSIM_ROOT=/home/user/isaacsim500
export ISAAC_PYTHON=/home/user/isaacsim500/python.sh
```

### Isaac Sim `No space left on device` watcher warnings

These warnings usually come from file-watch limits or temporary/cache pressure in Isaac Sim startup. The pipeline can still finish successfully. If it becomes fatal, clean Isaac logs/cache or increase the system watch limit.

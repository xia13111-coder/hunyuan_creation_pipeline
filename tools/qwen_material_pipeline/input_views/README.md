# Reference images

Place two to four photographs of one workpiece in a run-specific directory
outside this package, then pass them with repeated
`--visual-reference [ID=]IMAGE` arguments.

Use complementary views of the same physical asset. Images should be clear,
minimally occluded, and show the real surface appearance. Do not mix assets or
use an untextured CAD viewport as material evidence.

Reference images are runtime data. Do not commit customer images or reuse one
workpiece's evidence for another STEP/STP file.

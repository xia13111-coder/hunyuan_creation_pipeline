# Hunyuan 与 SAM3D 生成方式选择

[English](./generation-guide.md) | [中文](./generation-guide.zh.md) | [文档索引](./README.zh.md)

两条路径都会输出原始 GLB，之后通常继续执行 Hunyuan 精修、Blender 后处理和 Isaac Sim
物理。区别在于初始几何的来源：

- **Hunyuan** 根据单张图片生成完整资产，并推测不可见区域；
- **SAM3D** 先分割指定物体，再根据一张或多张照片重建。

## 快速选择

| 输入或要求 | 使用方式 | 原因 |
| --- | --- | --- |
| 一张干净商品图 | 先用 Hunyuan image-to-3D | 通常最容易得到视觉完整的资产。 |
| 同一物体的多个视角 | SAM3D `multi` | 多张图会参与同一次重建。 |
| 从复杂场景中选择一个目标 | SAM3D | 分割提示词可以指定物体。 |
| 很多互不相关的图片 | Hunyuan `--input-dir` | 每张图片是独立任务。 |
| 必须保留工程尺寸和装配变换 | STEP/STP CAD 路径 | 两种图片路径都不是工程测量工具。 |

## 主要区别

| 对比项 | Hunyuan | SAM3D |
| --- | --- | --- |
| 输入 | 图片 URL 或图片目录 | 一张图片或同一物体的多个视角 |
| 多张图片 | 分别生成多个任务 | `multi` 模式合并为一次重建 |
| 提示词 | 不使用；Hunyuan 只接收图片 | `--sam3d-prompt` 只选择二维目标 |
| 不可见区域 | 根据模型先验生成 | 仍需推测，但更多视角能减少不确定性 |
| 运行位置 | Tencent Cloud API | 重建阶段使用本地 GPU |
| 主要参数 | 输入和 `--face-count` | 模式、分割提示词、随机种子和采样步数 |
| 常见问题 | 隐藏结构看似合理但不真实 | 掩码错误、视角不一致或遮挡 |

Hunyuan 适合根据单张商品图快速生成资产。该项目不支持 Hunyuan 纯文本输入。注意
`--input-dir` 是批处理目录：同一物体的四张图会生成四个独立任务。

SAM3D 适合同一实物的多个互补视角，或需要从场景中指定一个目标。多视角图片应展示同一
实例，主体尺度接近，并尽量减少遮挡。

## 选择流程

```text
是否要求工程尺寸或装配精度？
├─ 是 -> 使用 STEP/STP
└─ 否
   ├─ 没有图片 -> 当前生成流程不支持
   ├─ 有同一物体的多个视角 -> SAM3D multi
   ├─ 需要从场景中选择目标 -> SAM3D single
   └─ 有一张主体清晰的图片 -> Hunyuan image-to-3D
```

## 质量限制

两条路径都不能恢复图片中不可见的内部结构、精确孔位、壁厚或真实尺寸。
`--len-x/y/z` 只调整最终包围盒，不能恢复零件级尺寸。

建议在精修前检查原始 GLB 的轮廓和部件完整性。精修可以简化几何并迁移外观，
但不能自动纠正错误的重建结构。用于仿真时，还应在最终 USD 中检查碰撞、质量、原点和
运动表现。

命令和参数见 [Hunyuan 模块](./modules/hunyuan.zh.md)和
[SAM3D 模块](./modules/sam3d.zh.md)。

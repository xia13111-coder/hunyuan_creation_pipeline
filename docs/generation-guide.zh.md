# Hunyuan 与 SAM3D 生成方式选择

[English](./generation-guide.md) | [中文](./generation-guide.zh.md) | [文档索引](./README.zh.md)

本项目提供两种从图片获得 3D 模型的路径，但它们解决的问题不同：

- **Hunyuan** 是生成式 image-to-3D / text-to-3D。它根据单张图片或文本语义生成完整模型，并推测输入中看不到的部分。
- **SAM3D** 是以目标分割和图片观测为基础的单视角/多视角重建。它先从图片中定位目标，再重建对应物体；多视角路径可以利用同一实物的多个角度。

它们都输出原始 GLB。当前生产流程默认继续执行 Hunyuan refine、Blender 后处理和 Isaac Sim 物理挂载，所以选择生成方式只决定前半段如何得到原始几何。

## 核心区别

| 对比项 | Hunyuan 生成 | SAM3D 重建 |
| --- | --- | --- |
| 主要目标 | 根据语义和外观生成一个完整 3D 资产 | 从一张或多张图片重建图片中的指定物体 |
| 输入 | 文本、单张图片 URL，或图片目录 | 单张图片或同一物体的多视角图片 |
| 多图含义 | `--input-dir` 中每张图片分别提交一个独立任务，不会合并成一个多视角模型 | `multi` 模式把目录中的图片作为同一物体的多个视角共同重建 |
| prompt 作用 | `--prompt` 是 text-to-3D 的模型描述 | `--sam3d-prompt` 只用于二维目标分割，不负责描述或生成 3D 结构 |
| 未观察区域 | 依靠生成模型推测，因此可以补全，但也可能产生与真实物体不同的结构 | 单图同样需要推测；多视角可以减少未观察区域，但图片之外仍不是精确测量 |
| 对输入背景的要求 | 主体清晰、遮挡少通常更稳定 | 目标必须能被 prompt 稳定分割；多图还应保持主体、尺度和构图一致 |
| 运行位置 | Tencent Cloud API，需要凭据、网络、服务配额和等待任务完成 | SAM3D 重建在本机 GPU 和 `hunyuan_sam3d` 环境运行 |
| 主要控制参数 | 输入图片或文本、`--face-count` | `--sam3d-mode`、分割 prompt、seed 和推理 steps |
| 常见风险 | 背面和遮挡区被合理化生成，但不一定符合真实物体；文本结果具有生成随机性 | mask 选错目标、多视角不是同一物体、视角差异过小或遮挡会导致几何不一致 |
| 后续流程 | 默认进入 Hunyuan refine | 默认也进入 Hunyuan refine，然后与 Hunyuan 路径汇合 |

## 什么时候使用 Hunyuan

以下情况优先使用 Hunyuan：

- 只有文本描述，还没有实物照片。
- 只有一张清晰图片，希望快速得到视觉上完整的模型。
- 目标是概念资产、通用道具或外观近似模型，不要求严格复现真实物体背面结构。
- 希望通过 `--face-count` 请求指定规模的原始模型。
- 本机不适合运行 SAM3D，但可以访问 Tencent Cloud 服务。

适合的例子：

- 根据 `industrial storage rack` 文本生成概念货架；
- 根据单张商品主图生成展示用资产；
- 批量把一个目录中的商品图片分别生成多个独立模型。

需要注意：`--input-dir` 是批处理目录，不是多视角输入。同一物体的四张图片放进该目录，会生成四个独立任务，而不是一个融合后的模型。

## 什么时候使用 SAM3D

以下情况优先使用 SAM3D：

- 已有同一实物的正面、侧面、背面等多个角度，希望尽量利用真实观测。
- 图片中有多个物体，需要通过 `--sam3d-prompt` 指定要提取的目标。
- 希望在本机完成第一阶段重建，并使用固定 seed 比较不同图片组合。
- 单图中目标边界明确，想先由 SAM3 分割目标再重建。

适合的例子：

- 用货架的前、后、左、右照片重建同一个货架；
- 从车间照片中使用 `industrial control cabinet` prompt 提取并重建控制柜；
- 对同一组多视角图片固定 seed，比较不同分割 prompt 的结果。

SAM3D 多视角输入应满足：

- 每张图片都是同一个实例，而不只是同一类别的不同物体；
- 主体尺度接近，尽量不要一张是远景、一张是局部特写；
- 视角互补，优先覆盖正面、侧面和背面；
- 遮挡较少，prompt 在每个视角中都能找到同一个目标；
- 不要把 mask 文件和普通输入图混在一起依赖文件名以外的隐式对应关系。

## 快速选择

| 当前条件 | 推荐路径 | 原因 |
| --- | --- | --- |
| 只有文字 | Hunyuan text-to-3D | SAM3D 必须有图片。 |
| 只有一张干净的商品图 | 先用 Hunyuan image-to-3D | 操作简单，适合快速得到完整视觉资产；也可用 SAM3D single 做对照。 |
| 有同一物体的多个互补角度 | SAM3D multi | 多张图片会共同参与同一模型重建。 |
| 场景复杂，需要从图片中指定某个物体 | SAM3D | 分割 prompt 可以明确选择目标。 |
| 需要批量处理很多互不相关的单图 | Hunyuan `--input-dir` | 目录中的图片会分别提交生成任务。 |
| 网络或 Hunyuan 生成服务暂时不可用 | SAM3D 第一阶段 | 原始重建可以在本地运行。正常后续 refine 仍需要 Hunyuan 服务。 |
| 必须保持工程尺寸、孔位和装配关系 | 两者都不适合，使用 STEP/STP CAD 路径 | 生成与图片重建都不是工程测量或 CAD 转换。 |

## 选择流程

```text
是否有图片？
├─ 否 -> Hunyuan text-to-3D
└─ 是
   ├─ 是否有同一物体的多个互补视角？
   │  ├─ 是 -> SAM3D multi
   │  └─ 否
   │     ├─ 是否需要从复杂场景中分割指定目标？
   │     │  ├─ 是 -> SAM3D single
   │     │  └─ 否 -> 优先 Hunyuan image-to-3D，可同时测试 SAM3D single
   └─ 是否要求工程级尺寸和装配准确性？
      └─ 是 -> 不使用生成路径，改走 STEP/STP
```

## 对结果质量的正确预期

Hunyuan 和 SAM3D 都不是 CAD 逆向工程工具。图片中看不到的内部结构、精确孔位、壁厚和真实尺寸不能仅靠生成模型保证。`--len-x/y/z` 只能在后处理阶段设置整体包围盒尺寸，不能恢复零件级工程尺寸。

建议先检查原始 GLB 的整体轮廓和部件完整性，再执行 Hunyuan refine。Refine 负责低模化和本地 Blender 处理，不会自动把错误的结构变成真实结构。对于关键仿真资产，应在最终 USD 中继续检查碰撞体、质量、原点和运动行为。
